# 👑 Mushahid Hussain — Web Developer Portfolio

An exact, luxury editorial web developer portfolio built with modern React, Tailwind CSS, Lucide Icons, and bespoke gold & emerald styling.

Live Reference: [https://mushahid-hussain-web-developer-port-seven.vercel.app/](https://mushahid-hussain-web-developer-port-seven.vercel.app/)

---

## ✨ Features & Highlights

- **👑 Luxury Editorial Aesthetic:** Bespoke color palette featuring Deep Emerald (`#11261B`), Metallic Gold (`#C5A059`), Soft Warm Cream (`#F8F5EE`), and editorial serif typography (*Cormorant Garamond*, *Playfair Display*, *JetBrains Mono*, *Plus Jakarta Sans*).
- **🌀 Rotating Gold Monogram Seal:** Dynamic SVG seal with animated circular typography textpath (`• 𝕄𝕦𝕤𝕙𝕒𝕙𝕚𝕕 ℍ𝕦𝕤𝕤𝕒𝕚𝕟 • 𝕎𝕖𝕓 𝔻𝕖𝕧𝕖𝕝𝕠𝕡𝕖𝕣 •`).
- **🎯 Dynamic Section Navigation:** Smooth hash-based routing (`#home`, `#about`, `#services`, `#skills`, `#experience`, `#courses`, `#why-choose-me`, `#testimonials`, `#projects`, `#resume`, `#contact`).
- **💼 Comprehensive Sections:**
  1. **Hero:** High-impact introduction, interactive badge, portrait image, and call-to-actions.
  2. **About Me:** Biography, developer philosophy, background story, and key metrics.
  3. **Services:** Full-stack engineering, API design, database architecture, and performance optimization.
  4. **Skills Matrix:** Categorized technical skill pills with proficiency filters (Frontend, Backend, Databases, DevOps).
  5. **Career Experience:** Interactive timeline of professional roles, companies, and achievements.
  6. **Courses & Badges:** Official accreditation badges (Claude AI, Claude Dev, WeVersity, etc.).
  7. **Why Choose Me:** Value proposition, deliverables comparison, and client satisfaction guarantees.
  8. **Testimonials:** Verified client reviews with ratings, company names, and locations.
  9. **Projects Showcase:** Filterable project cards (SaaS, E-Commerce, Full-Stack, APIs) with live demo buttons and comprehensive detail modal popup.
  10. **Interactive Resume:** Full preview, printable layout, and download-ready CV modal.
  11. **Contact & Socials:** Direct WhatsApp click-to-chat (`03290725117`), email outreach, GitHub, and LinkedIn links.
- **📱 100% Fully Responsive:** Tailored for mobile phones, tablets, laptops, and ultra-wide displays.
- **⚡ Offline & Self-Contained:** All 22 project screenshots, portraits, and badge assets are bundled locally in `/assets/`.

## 🚀 Quick Start (Running Locally)

### Option 1: Using Node.js (Recommended)
Run the built-in HTTP server:
```bash
npm start
```
Or:
```bash
node server.js
```
Then open your browser at:
```
http://localhost:3456/
```

### Option 2: Using VS Code Live Server or any static file server
- Right-click `index.html` and select **"Open with Live Server"**.
- Or use python:
  ```bash
  python -m http.server 3000
  ```

## 🌐 Deploy to Vercel or GitHub Pages

### Deploying to Vercel:
1. Install Vercel CLI: `npm i -g vercel`
2. Run in the portfolio directory:
   ```bash
   vercel
   ```
3. Follow the CLI prompts to deploy in seconds!

### Deploying to GitHub Pages:
1. Push this folder to a GitHub repository.
2. In repository **Settings > Pages**, select the `main` branch and `/` root directory.
3. Save, and your portfolio will be live!
